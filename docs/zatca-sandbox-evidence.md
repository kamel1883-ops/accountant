# أدلة اختبار ساندبوكس الهيئة (غير سرية)

تاريخ التشغيل: 2026-09-29 18:53 Asia/Riyadh  
الآلة: بيئة التطوير المحلية لجداره (`backend` + SDK الرسمي .NET 8)  
الأمر: `npm run zatca:sandbox`  
النتيجة النهائية: **SANDBOX_OK**

لا يتضمن هذا الملف OTP ولا توكنات ولا شهادات ولا مفاتيح خاصة.

## Endpoint المستخدم (ساندبوكس المطوّرين فقط)

الأساس:

`https://gw-fatoora.zatca.gov.sa/e-invoicing/developer-portal`

هذا **ليس** مسار الإنتاج:

- الإنتاج الحي: `https://gw-fatoora.zatca.gov.sa/e-invoicing/core`
- المحاكاة: `https://gw-fatoora.zatca.gov.sa/e-invoicing/simulation`

الكود يختار الرابط من حقل `environment` لكل منشأة (`backend/src/modules/zatca/env.ts`). شهادات كل عميل صف مستقل `ZatcaDevice.tenantId` فريد.

## خطوات الاختبار ورمز HTTP (بدون أسرار)

| الخطوة | المسار التقريبي | HTTP | النتيجة |
|---|---|---|---|
| 1. إنشاء CSR عبر SDK | محلي (fatooraNet) | — | نجح |
| 2. شهادة الامتثال CCSID | `POST /compliance` | **200** | OK |
| 3أ. فاتورة امتثال قياسية | `POST /compliance/invoices` | **200** | OK |
| 3ب. إشعار دائن قياسي | `POST /compliance/invoices` | **200** | OK |
| 3ج. إشعار مدين قياسي | `POST /compliance/invoices` | **200** | OK |
| 4. شهادة تالية داخل الساندبوكس (ليست إنتاج مكلّف حي) | `POST /production/csids` على **developer-portal** | **200** | OK |
| 5. تخليص فاتورة تجريبية | `POST /invoices/clearance/single` | **200** | CLEARED |

بيانات البائع في هذا الاختبار هي أرقام الهيئة التجريبية العلنية (`399999999900003` / مشتري `399999999800003`) وليست منشأة عميل.

## XML

عينة **غير موقّعة** وبدون امتداد ختم (لا مفتاح ولا XAdES) في:

`docs/zatca-sandbox-unsigned-sample.xml`

الفاتورة المقبولة في التخليص كانت موقّعة محلياً بالـ SDK ثم أُرسلت للساندبوكس. لا نحتفظ بنسخة موقّعة هنا لأنها تحمل مادة الشهادة.

## ما لم يُثبت بهذا الاختبار

حماية التشغيل على السيرفر الحي، النسخ الاحتياطي، تجربة المستخدم الكاملة على الموقع المنشور، أو ربط إنتاج لمنشأة حقيقية.

## تأكيدات من الكود (مراجعة)

- الواجهة لا تستقبل `privateKeyPem` ولا أسرار CSID (`publicDevice` يعيد أعلام hasCsr/hasCcsid/hasPcsid فقط).
- لا يوجد عمود OTP في قاعدة البيانات؛ الرمز يُرسل في ترويسة الطلب لمرة التهيئة ثم يُمسح من حقل الشاشة.
- المفاتيح تُشفَّر قبل الحفظ (`protectDevice` / AES-256-GCM).
- كل منشأة لها `ZatcaDevice` واحد مربوط `tenantId @unique` وسجل `ZatcaSubmission` مفهرس بالمنشأة.
- فاتورة التجربة ممنوعة على بيئة `production`.
