# جداره Finance — Frontend

React + TypeScript + Vite + Tailwind. تطبيقان في مشروع واحد:

- **تطبيق المحاسبة** (`/`): يسجّل دخوله مستخدمو المنشآت (Tenants)، ويتحدث مع كل نقاط `/api/*` في الباك إند.
- **بوابة المالك** (`/owner`): دخول منفصل تماماً (`ownerApi` / `jadara_owner_token` بمفتاح تخزين مختلف)، يتحدث مع `/api/owner/*` فقط.

## التشغيل محلياً

```bash
npm install
cp .env.example .env      # عدّل VITE_API_URL إذا الباك إند مو على localhost:4000
npm run dev                 # يفتح على http://localhost:5173
```

افتح `http://localhost:5173` لتطبيق المحاسبة، و `http://localhost:5173/owner` لبوابة المالك.

## ملاحظات

- ما فيه أي مكتبة توجيه (react-router) عن قصد — التطبيق بسيط بما يكفي لتبديل شاشات
  عبر state داخل `TenantApp.tsx` و`OwnerApp.tsx`. لو تبي روابط مستقلة قابلة للمشاركة
  لكل شاشة لاحقاً، هذا أول شي تضيفه.
- كل نداءات API موجودة في `src/api/client.ts` فقط — أي نقطة API جديدة تُضاف هناك.
- التصميم بـ Tailwind مباشر داخل الملفات (لا CSS منفصل لكل صفحة) لسهولة القراءة
  والتعديل السريع.
- الخطوة القادمة الطبيعية: ربط هذا الفرونت إند بالباك إند فعلياً (شغّل الاثنين
  محلياً بنفس الوقت)، وتجربته على بيانات حقيقية قبل النشر.
